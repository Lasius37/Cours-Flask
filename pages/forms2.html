    Comprendre les formulaires avancés

    Jusqu'à présent, les formulaires ont été écrits directement en HTML, puis leurs données ont été récupérées avec request.form.

    Cette méthode convient à des formulaires simples, mais elle oblige à gérer manuellement :

    • la création des champs HTML
    • la récupération des données
    • la conversion des valeurs
    • la validation des données
    • l'affichage des messages d'erreur
    • la protection contre certaines requêtes malveillantes

    Flask-WTF permet de définir le formulaire dans une classe Python. Cette classe contient les champs, leurs propriétés et leurs règles de validation.

    Formulaire HTML classique Formulaire Flask-WTF
    Champs écrits directement dans le template Champs définis dans une classe Python
    Données lues avec request.form Données accessibles avec form.field.data
    Validation écrite manuellement Validation assurée par des validateurs
    Messages d'erreur créés manuellement Erreurs associées automatiquement aux champs

    Installer Flask-WTF

    Installer Flask-WTF dans l'environnement virtuel du projet : 

    pip install Flask-WTF

    Ajouter ensuite la dépendance au fichier requirements.txt : 

    pip freeze > requirements.txt

    Configurer la clé secrète

    Flask-WTF utilise une clé secrète pour protéger les formulaires contre les requêtes falsifiées.

    Dans la fabrique d'application : 

    def create_app():
    app = Flask(__name__)

    app.config["SECRET_KEY"] = "development-key"

    return app

    Cette clé permet notamment de créer et de vérifier le jeton CSRF associé au formulaire.

    La valeur utilisée dans cet exemple convient uniquement au développement. Dans une véritable application, la clé doit être longue, imprévisible et ne pas être écrite directement dans le code partagé.

    Créer une classe de formulaire

    Les classes de formulaires peuvent être placées dans un fichier forms.py à l'intérieur du package correspondant à la fonctionnalité. 

    app/
└── books/
    ├── __init__.py
    ├── forms.py
    ├── routes.py
    └── templates/
        └── books/
            └── form.html

    Dans app/books/forms.py : 

    from flask_wtf import FlaskForm
from wtforms import IntegerField, StringField, SubmitField
from wtforms.validators import DataRequired, Length, NumberRange


class BookForm(FlaskForm):
    title = StringField(
        "Titre",
        validators=[
            DataRequired(),
            Length(max=200)
        ]
    )

    publication_year = IntegerField(
        "Année de publication",
        validators=[
            DataRequired(),
            NumberRange(
                min=1000,
                max=2100
            )
        ]
    )

    submit = SubmitField("Enregistrer")

    La classe BookForm hérite de FlaskForm. Chaque attribut de la classe représente un champ.

    Choisir les champs

    WTForms fournit plusieurs classes correspondant aux principaux champs d'un formulaire.

    Classe Utilisation
    StringField Saisir un texte court
    TextAreaField Saisir un texte long
    IntegerField Saisir un nombre entier
    DecimalField Saisir un nombre décimal
    DateField Saisir une date
    BooleanField Créer une case à cocher
    SelectField Créer une liste de sélection
    RadioField Créer un groupe de boutons radio
    SubmitField Créer le bouton d'envoi

    Le premier argument d'un champ correspond généralement à son libellé : 

    title = StringField("Titre")

    Les données saisies sont ensuite accessibles avec : 

    form.title.data

    WTForms convertit les valeurs selon le type de champ. Par exemple, IntegerField fournit une valeur entière lorsque la saisie est valide.

    Valider les données

    Un validateur vérifie qu'une valeur respecte une règle. Les validateurs sont placés dans une liste associée au champ : 

    title = StringField(
    "Titre",
    validators=[
        DataRequired(),
        Length(min=2, max=200)
    ]
)
    Validateur Vérification
    DataRequired() La valeur ne doit pas être vide après sa conversion
    InputRequired() Une valeur doit avoir été envoyée par le formulaire
    Length() La longueur du texte respecte les limites indiquées
    NumberRange() Le nombre appartient à l'intervalle indiqué
    Optional() Le champ peut rester vide
    EqualTo() La valeur correspond à celle d'un autre champ

    Un message personnalisé peut être fourni au validateur : 

    DataRequired(
    message="Le titre est obligatoire."
)

    Plusieurs validateurs peuvent être appliqués successivement au même champ.

    Traiter le formulaire

    La classe de formulaire est importée dans le fichier contenant les routes. 

    from flask import redirect, render_template, url_for

from ..extensions import db
from ..models import Book
from . import books_bp
from .forms import BookForm


@books_bp.route("/create", methods=["GET", "POST"])
def create_book():
    form = BookForm()

    if form.validate_on_submit():
        book = Book(
            title=form.title.data,
            publication_year=form.publication_year.data
        )

        db.session.add(book)
        db.session.commit()

        return redirect(
            url_for("books.list_books")
        )

    return render_template(
        "books/form.html",
        form=form
    )

    La méthode validate_on_submit() renvoie True uniquement lorsque :

    • le formulaire a été envoyé
    • les données respectent tous les validateurs
    • le jeton CSRF est valide

    Si le formulaire est simplement affiché ou s'il contient une erreur, le template est de nouveau rendu avec le même objet form.

    Afficher le formulaire

    Dans app/books/templates/books/form.html : 

    <form method="post">
    {{ form.hidden_tag() }}

    <div>
        {{ form.title.label }}
        {{ form.title() }}
    </div>

    <div>
        {{ form.publication_year.label }}
        {{ form.publication_year() }}
    </div>

    {{ form.submit() }}
</form>

    Chaque champ fournit plusieurs éléments :

    Instruction Résultat
    form.title.label Afficher la balise <label>
    form.title() Afficher le champ HTML
    form.title.data Accéder à la valeur du champ
    form.title.errors Accéder aux erreurs du champ

    Des attributs HTML peuvent être ajoutés lors de l'affichage : 

    {{ form.title(
    class="form__input",
    placeholder="Titre du livre"
) }}

    La méthode hidden_tag() affiche les champs cachés du formulaire, notamment le jeton CSRF.

    Afficher les erreurs

    Lorsqu'un champ est invalide, ses messages sont disponibles dans sa propriété errors. 

    <div>
    {{ form.title.label }}
    {{ form.title() }}

    {% for error in form.title.errors %}
        <p class="error">{{ error }}</p>
    {% endfor %}
</div>

    Le même principe doit être appliqué à chaque champ susceptible de produire une erreur.

    Il est également possible d'afficher toutes les erreurs du formulaire : 

    {% for field_name, errors in form.errors.items() %}
    {% for error in errors %}
        <p class="error">{{ error }}</p>
    {% endfor %}
{% endfor %}

    Créer une liste de sélection

    Un champ SelectField permet de choisir une valeur dans une liste.

    Il peut notamment servir à associer un livre à un auteur.

    Dans forms.py : 

    from wtforms import SelectField


class BookForm(FlaskForm):
    # Autres champs

    author_id = SelectField(
        "Auteur",
        coerce=int,
        validators=[
            DataRequired()
        ]
    )

    Les données envoyées par un formulaire HTML sont normalement des chaînes de caractères. Le paramètre coerce=int convertit la valeur sélectionnée en entier.

    Les choix sont définis dans la fonction de vue à partir des auteurs présents dans la base : 

    form = BookForm()

authors = db.session.execute(
    db.select(Author).order_by(Author.name)
).scalars().all()

form.author_id.choices = [
    (author.id, author.name)
    for author in authors
]

    Chaque choix contient :

    • la valeur envoyée au serveur : author.id
    • le texte affiché à l'utilisateur : author.name

    Lors de la création du livre : 

    book = Book(
    title=form.title.data,
    publication_year=form.publication_year.data,
    author_id=form.author_id.data
)

    Les choix doivent être définis avant l'appel à validate_on_submit(), afin que WTForms puisse vérifier que la valeur envoyée appartient bien à la liste.

    Préremplir un formulaire

    Un même formulaire peut être utilisé pour créer et modifier un objet.

    La fonction get_or_404() permet d'abord de récupérer le livre : 

    @books_bp.route(
    "/<int:book_id>/update",
    methods=["GET", "POST"]
)
def update_book(book_id):
    book = db.get_or_404(Book, book_id)

    form = BookForm(obj=book)

    authors = db.session.execute(
        db.select(Author).order_by(Author.name)
    ).scalars().all()

    form.author_id.choices = [
        (author.id, author.name)
        for author in authors
    ]

    if form.validate_on_submit():
        book.title = form.title.data
        book.publication_year = form.publication_year.data
        book.author_id = form.author_id.data

        db.session.commit()

        return redirect(
            url_for(
                "books.book_detail",
                book_id=book.id
            )
        )

    return render_template(
        "books/form.html",
        form=form
    )

    Le paramètre obj=book utilise les propriétés de l'objet pour fournir les valeurs initiales des champs.

    Après l'envoi, les nouvelles valeurs sont récupérées dans les propriétés data du formulaire.

    Créer une validation personnalisée

    Les validateurs fournis par WTForms couvrent les besoins les plus fréquents. Une règle propre à l'application peut toutefois nécessiter une validation personnalisée.

    Une méthode dont le nom commence par validate_ et se termine par le nom du champ est automatiquement utilisée pour valider ce champ. 

    from wtforms.validators import ValidationError


class BookForm(FlaskForm):
    title = StringField(
        "Titre",
        validators=[
            DataRequired(),
            Length(max=200)
        ]
    )

    def validate_title(self, field):
        if field.data.lower() == "livre sans titre":
            raise ValidationError(
                "Ce titre n'est pas autorisé."
            )

    La méthode reçoit le champ à vérifier. Si la valeur est invalide, elle lève une exception ValidationError contenant le message à afficher.

    Erreurs fréquentes

    • Oublier de configurer SECRET_KEY : Flask-WTF ne peut pas sécuriser correctement le formulaire .
    • Oublier methods=["GET", "POST"] sur la route : Flask refuse l'envoi du formulaire avec la méthode POST .
    • Oublier form.hidden_tag() dans le template : le jeton CSRF n'est pas envoyé .
    • Utiliser directement request.form après avoir validé un formulaire Flask-WTF : les conversions effectuées par les champs WTForms ne sont pas utilisées .
    • Enregistrer les données sans appeler validate_on_submit() : des données invalides peuvent être enregistrées .
    • Oublier d'afficher les erreurs dans le template : l'utilisateur ne comprend pas pourquoi le formulaire est refusé .
    • Oublier coerce=int dans un SelectField contenant des identifiants : la valeur reste une chaîne de caractères .
    • Définir les choix d'un SelectField après la validation : WTForms ne peut pas vérifier correctement la valeur envoyée .
    • Donner à une validation personnalisée un nom incorrect : la méthode n'est pas automatiquement exécutée .
