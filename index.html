Flask, c'est quoi ?

Flask est un micro-framework web écrit en Python qui permet de créer des sites et des applications web de manière simpleet flexible. Là où HTML, CSS et JavaScript s’occupent de l’interface visible dans le navigateur, Flask gère la logique et les échanges côté serveur : il constitue le cœur de fonctionnement de l’application. Grâce à sa légèreté et à sa simplicité, Flask est particulièrement adapté pour apprendre le développement web, créer des prototypes rapidement ou développer des applications personnalisées avec une architecture entièrement maîtrisée.
